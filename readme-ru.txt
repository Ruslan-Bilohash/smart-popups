Free professional popup builder for WordPress. Create beautiful popups with device targeting, countdown timers, page rules and full design customization.

== Description ==

**Bilohash Smart Popups** — це повністю безкоштовний і потужний конструктор попапів для WordPress.

### Основні можливості:

- **Тригери показу**: Time Delay, Scroll (50%), Exit Intent
- **Зворотний відлік (Countdown Timer)** з довільною датою закінчення
- **Кастомні іконки** (будь-які емодзі)
- **Повне налаштування дизайну**:
  - Колір фону
  - Акцентний колір
  - Колір заголовка
  - Колір тексту
- **Налаштування розміру**:
  - Ширина попапу (px, vw, %)
  - Висота попапу (auto, px, vh)
- **Таргетинг по пристроях**:
  - Окремо вмикати/вимикати на Desktop, Tablet та Mobile
- **Таргетинг по сторінках**:
  - Всі сторінки
  - Тільки головна сторінка
  - Конкретні сторінки (за ID або slug)
- **Захист від повторного показу** — не показувати після закриття
- **Кнопка з посиланням**
- **Легка та швидка** — не навантажує сайт
- **Адаптивний дизайн** — добре виглядає на всіх пристроях
- **Безкоштовний** і з відкритим кодом (GPLv2)

Плагін ідеально підходить для:
- Акцій та знижок
- Збору лідів
- Підписки на розсилку
- Оголошень та важливих повідомлень
- Спеціальних пропозицій

== Installation ==

1. Завантажте плагін у папку `/wp-content/plugins/bilohash-smart-popups`
2. Активуйте плагін у розділі **Plugins**
3. Перейдіть у меню **Smart Popups** в адмін-панелі WordPress
4. Налаштуйте попап і збережіть зміни

== Frequently Asked Questions ==

= Чи плагін безкоштовний? =
Так. Плагін повністю безкоштовний і поширюється за ліцензією GPLv2.

= Чи можна створити кілька попапів? =
Так. Ви можете створювати необмежену кількість попапів з різним дизайном і правилами показу.

= Чи можна показувати попап тільки на певних сторінках? =
Так. Доступні три режими: Всі сторінки, Тільки головна, Конкретні сторінки (вкажіть ID або slug).

= Чи є зворотний відлік? =
Так. Ви можете увімкнути таймер зворотного відліку з будь-якою датою закінчення.

= Чи підтримується таргетинг по пристроях? =
Так. Ви можете окремо вмикати або вимикати показ попапу на комп’ютерах, планшетах та смартфонах.
