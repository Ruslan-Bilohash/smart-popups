## ✨ Возможности

- **Несколько триггеров** — Показ по времени, при прокрутке (50%), при выходе с сайта (Exit Intent)
- **Таймер обратного отсчёта** — Красивый countdown с любой датой окончания
- **Кастомные иконки** — Можно использовать любое эмодзи
- **Полная кастомизация дизайна** — Цвет фона, акцентный цвет, цвет заголовка и текста
- **Настройка размеров** — Ширина и высота попапа (px, vw, vh, auto)
- **Таргетинг по устройствам** — Отдельное включение/отключение на Desktop, Tablet и Mobile
- **Таргетинг по страницам** — Показывать на всех страницах, только на главной или на конкретных
- **Защита от повторного показа** — Не показывать попап снова после закрытия
- **Лёгкий и быстрый** — Оптимизированный код без лишних скриптов
- **Полностью адаптивный**
- **100% бесплатно и с открытым кодом**

## 📦 Установка

1. Скачайте последнюю версию с [GitHub](https://github.com/Ruslan-Bilohash/bilohash-smart-popups/releases) или WordPress.org
2. Загрузите папку плагина в `/wp-content/plugins/`
3. Активируйте плагин **Bilohash Smart Popups** в разделе «Плагины»
4. Перейдите в меню **Smart Popups** в админ-панели WordPress
5. Настройте попап и сохраните изменения

## 🚀 Как пользоваться

1. Перейдите в **Smart Popups → Настройки**
2. Включите попап
3. Настройте содержимое, цвета, размеры и триггеры
4. Укажите правила показа по устройствам и страницам
5. Сохраните — готово!
